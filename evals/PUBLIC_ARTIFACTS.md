# Public Evaluation Artifacts

This directory contains public-redacted derivatives of the original frozen evaluation artifacts. The transformation removes machine-local paths and redirects internal process-document identities to concise public provenance notes. Datasets, model outputs, metrics, case labels, attack outcomes, and experiment conclusions are unchanged.

`public_manifest.json` records the original and public SHA-256 values for every modified artifact. The historical `W*` strings retained in filenames and machine fields are stable experiment identifiers, not the organization of the public documentation.
