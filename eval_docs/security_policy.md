# Information Security Policy

## Passwords

Passwords must be at least 14 characters long. Passwords must not be reused across company and personal accounts. Password managers are approved for storing work credentials.

## Multi-Factor Authentication

Multi-factor authentication is required for email, VPN, source code repositories, finance systems, and production infrastructure. Hardware security keys are required for privileged administrator accounts.

## Data Classification

Company data is classified as Public, Internal, Confidential, or Restricted. Customer personal data is Restricted. Product roadmap documents are Confidential unless explicitly approved for public release.

## Incident Reporting

Suspected security incidents must be reported to the Security team within 1 hour. Lost or stolen company devices must be reported immediately, even if the device is encrypted.

## Vendor Access

Vendor access to internal systems requires a named business owner, a signed data processing agreement, and an expiration date. Vendor accounts must be reviewed every 90 days.
